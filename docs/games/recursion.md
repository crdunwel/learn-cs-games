# Recursion Reverie

Twelve question families ask for return values, print order, base/recursive parts, Fibonacci values or call counts, permutation counts, and a recursive binary-search return index. All questions have `reviewSteps` with concrete worked reasoning. Eight Learn paths include Fibonacci, swap/backtrack permutations, and recursive binary search.

The original eight families retain their C semantics and domains. For a decrement-by-d total, d is positive and the stopping case is n<=0: count ceil(n/d) additions, including a final argument below zero. Printing before recursion descends; printing after it ascends. A boolean C comparison contributes 1 or 0. Array recursion checks the bound before reading. Power uses nonnegative exponents. The special recurrence uses its own two base cases. Every result fits a 16-bit signed int.

## New bounded families

- **Fibonacci returns:** n=0…10, with `fib(0)=0`, `fib(1)=1`, and two recursive branches added. The generator recursively derives the result; the independent guard builds a bottom-up table. The largest returned value is 55.
- **Fibonacci calls:** the same displayed function, but ask how many invocations run, including the initial invocation and every base invocation. C(0)=C(1)=1; C(n)=1+C(n−1)+C(n−2). Repeated invocations are counted separately; there is no cache. The largest count is 177. Worked review constructs every needed value from the bases, pairing adjacent computations to stay within six rows.
- **Permutations:** a writable, null-terminated array contains the distinct prefix of ABCDE, length 2…5. `permute` swaps a candidate into `pos`, recursively fills the remaining suffix, and swaps back. At pos==size it prints one whole word. Choosing unused letters gives size! distinct leaves, at most 120. The validator independently enumerates arrangements without using swaps or a factorial helper. Native tests capture actual C output, assert each original letter occurs once in each word, reject duplicate outputs, and confirm that the word is restored after the call. The prompt explicitly requires a writable array rather than a C string literal.
- **Recursive binary search:** arrays have length 5…10, first value 1…20, gap 2…8; keys are present or one below/above the array. Inclusive bounds start at 0 and size−1. The empty-range check precedes the read. Each mismatch removes mid and the impossible half; each waiting call returns its child's index unchanged. The generator recursively traces calls; validation uses an iterative trace and a separate linear lookup. Every 7,980 array/key combination is checked, including native execution; an additional empty-range native call checks termination before access.

Numeric results accept equivalent arithmetic via the shared answer parser. Print sequences retain sequence metadata so comma/arrow/bracket spacing is cosmetic. Worked rows show the base case and the combining operation; a returned value, an array index, and a count of calls must remain distinct concepts.

## Extension and verification

Level 1 topic order is `sum, print, array-sum, base-case, fibonacci`. Levels 2/3 preserve the original eight first, followed by `fibonacci, fibonacci-calls, permutations, recursive-search`. Exact deterministic tapes in test helpers must track this order. New choices consume only the supplied RNG. These practice changes do not alter persisted mock-exam templates.
